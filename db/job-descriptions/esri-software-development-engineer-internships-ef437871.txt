Esri Software Development Engineer Internship

Build Technology That Matters
As a Software Development Engineer Intern at Esri, you will work closely with experienced software developers and engineers to build innovative analytics software used across industries. You will contribute to ArcGIS products while gaining hands-on experience with coding, testing, troubleshooting, collaboration, and modern software development practices.

What You’ll Experience
Collaborate with members of the product development team to design, develop, and test software.

Assist with maintaining and improving existing software applications.

Write quality code, apply coding standards, use version control, participate in code reviews, and maintain code in a shared repository.

Identify and resolve issues in software code by analyzing and troubleshooting software defects.

Stay current on emerging technologies and trends in software development.

Real Projects Interns May Work On
Research and implement a large language model for testing or test automation.

Support DevOps work using Python, Jenkins, Ansible, GitHub, and Docker.

Explore machine learning-driven GIS for aerial detection or pattern discovery in large datasets.

Develop augmented reality, Android, JavaScript, web, mobile, 3D, or disaster-response applications connected to ArcGIS.

What You’ll Gain
Hands-on software engineering experience connected to ArcGIS and geospatial technology.

Exposure to code reviews, shared repositories, testing, troubleshooting, DevOps, automation, mobile, web, data science, or machine learning projects.

Mentorship, feedback, and a clearer view of software development career paths at Esri.

Connections with fellow interns and professionals across the company.

We’re Excited to Meet Students Who
Are currently enrolled in a four-year undergraduate, graduate, or PhD program at a university in the United States, majoring in computer science, computer engineering, software engineering, or a related field graduating in 2027 or 2028.

For undergraduate students, are in junior or senior standing.

Have knowledge in one or more of these areas: C++, C#, Python, Java, JavaScript, TypeScript, HTML5, iOS, Android, or Windows mobile technology. GIS experience is not required.

Are curious, collaborative, and interested in learning through real software development work.

Can complete a consecutive, onsite 12-week internship beginning in May or June 2027.

Are able to obtain work authorization in the United States in 2027.
